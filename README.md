### 💼 Featured Projects  

#### 🎬 [Dojo Movie](https://github.com/Raihan260/Dojo_Movie)
> **Android Ticket Booking App**  
A movie ticket booking application that allows users to browse available films, view details, and make purchases.  
Each user’s purchase history is stored locally using **SQLite**, and integrated with **Google Maps API** to locate nearby cinemas.  
**Tech:** Kotlin, SQLite, Android Studio, Google Maps API  

---

#### 📰 [BeritaID](https://github.com/Raihan260/Berita_ID)
> **Modern News Portal App**  
A mobile news application designed to display multiple categories of news in a fast and simple interface.  
The app focuses on responsiveness and accessibility to enhance user reading experience.  
**Tech:** Kotlin, Android Studio, XML UI  

---

#### 🛍️ [Christian Wijaya E-Commerce](https://github.com/Raihan260/ChristianWijaya_E-Commerce)
> **Fashion E-Commerce Website**  
A modern e-commerce website built for a fashion brand, enabling users to search, view, and purchase products.  
It also includes a registration page for aspiring models and an “About Us” page introducing the brand identity.  
**Tech:** HTML, CSS, JavaScript  

---

#### 🌍 [SDG Adventure](https://github.com/Raihan260/SDG_Adventure_2)
> **Interactive SDGs Educational Game**  
An interactive mobile application inspired by the **UN Sustainable Development Goals (SDGs)**.  
Players can explore missions, learn about real-world sustainability challenges, and complete tasks representing each SDG target.  
**Tech:** Flutter (Dart), Firebase Auth, Figma  

---

#### 🚦 [Traffic Detection (AI)](https://github.com/Raihan260/Traffic_Detection_FasterRCNN)
> **AI-Based Traffic Density Detection System**
